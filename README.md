# My IG Content 2026

Archive of Claude project knowledge files and resources for Oman real estate Instagram content creation.

## Project Overview

This repository contains knowledge files and resources for an Omani content creator specializing in real estate investment education, focusing on property laws and regulations for foreign investors in Oman.

## Repository Structure

```
IG-content/
├── README.md
└── knowledge-files/
    ├── project-context.md          # Project memory, context, and session history
    └── Instagram_Algorithm_2025_Knowledge_Base.md  # Complete IG algorithm guide
```

## Key Topics Covered

### Legal Topics
- 10-year structural warranty (Article 634)
- Usufruct vs freehold ownership
- Inheritance laws for foreign property owners
- Restricted zones for foreign buyers
- Royal Decree 29/2018
- Golden Visa requirements

### Content Strategy
- Instagram Algorithm 2025 insights
- Hook templates (Arabic & English)
- Carousel, Reels, and Stories strategies
- SEO and hashtag optimization
- Engagement tactics

### Tools & Workflows
- Google Gemini Veo 3 for video generation
- CapCut for post-production
- Hybrid AI + manual workflow for Arabic RTL text
